# Мои задачи

Flutter-приложение для планирования задач с локальным хранением в Hive,
календарём и таймером фокуса. Интерфейс на русском языке.

## Возможности

- Создание, редактирование и перенос задач на другую дату.
- Сортировка по времени и единая выбранная дата на главной и в календаре.
- Проверка пересечений при добавлении, редактировании и отмене удаления.
- Интервалы через полночь: время окончания раньше начала означает следующий
  день. Такая задача отображается на обоих днях. Одинаковое время запрещено;
  соседние интервалы разрешены. Завершённые задачи сохраняют занятое время.
- Свайп вправо отмечает выполнение, влево удаляет. Те же действия доступны
  через флажок и меню задачи. Удаление можно отменить в течение 8 секунд.
  Если восстановление не удалось, сообщение с кнопкой «Повторить» остаётся
  до повторной попытки или закрытия пользователем.
- Полупрозрачное боковое меню со скруглением, единые карточки задач и
  отметки занятых дней. Список на главной прокручивается внутри белой панели.
- Форма задачи в нижней панели; выбор времени показывает длительность
  и переход на следующий день.
- Короткие анимации выбора, выполнения и переходов учитывают системное
  уменьшение движения; на iOS сохранён жест возврата назад.
- Таймер фокуса: запуск, пауза, сброс, переключение на перерыв; длительность
  фокуса и перерыва сохраняется в настройках. Есть шкала прогресса,
  запуск следующего сеанса и быстрый выбор длительности в настройках.

Таймер продолжает отсчёт при переходах между экранами и учитывает время в фоне.
После полного закрытия процесса приложения сеанс сбрасывается. Фонового звука
и системных уведомлений нет.

## Запуск и проверки

Требуется Flutter с Dart 3.12.2 или новее.

```sh
flutter pub get
flutter run
flutter analyze
flutter test
```

Проверки логики используют временные файлы Hive и имитируют ошибки записи.
Тесты интерфейса используют Hive в памяти, чтобы не зависеть от файлового ввода
и вывода внутри виртуального времени Flutter.

## Подпись Android release

Скопируйте `android/key.properties.example` в `android/key.properties` и
укажите свой release/upload keystore, его пароли и alias. Путь `storeFile`
может быть абсолютным или относительным к каталогу `android/`.
`key.properties` и файлы ключей исключены из Git.

После настройки выполните `flutter build appbundle --release`.
Без этих данных release-сборка завершается с сообщением о необходимости
настроить подпись. Debug-сборка работает отдельно со стандартным debug-ключом.

## Данные

Задачи хранятся в боксе `tasks`, настройки — в `settings`.
Существующие номера полей и идентификатор адаптера задач сохранены.
Изменения отображаются после успешной записи; при ошибке пользователь видит
сообщение и может повторить действие. Очистка данных при ошибке запуска
не выполняется; на экране ошибки доступна повторная попытка загрузки.
